# Тактический инвентарь (gearinventory)

Мод для Minecraft 1.21.1, NeoForge 21.1+. Нужен Curios API 9.4+.

- Надетая броня даёт свои карманы. Вещи лежат внутри самой брони.
- Слоты рюкзака и элитр (Curios), корзина, крафт 2×2 без книги рецептов.
- Режим лута у сундука, бочки, эндер-сундука, шалкера, воронки, раздатчика и выбрасывателя.
- Полоса статов в инвентаре вместо полосок на экране, виньетка и сердцебиение.
- TaCZ берёт патроны из карманов, Sophisticated Backpacks работает из слота рюкзака (оба мода необязательны).

## Управление

- **E**: снаряжение. В креативе обычный инвентарь.
- **Shift+клик**: перенести. **Ctrl+клик**: в корзину (броню с вещами нельзя).

## Размеры

Датапак: `data/gearinventory/data_maps/item/armor_storage.json`, для предмета или тега `{"width": 6, "height": 4}`.
Не больше 9×6. Если размер уменьшить, лишние вещи при открытии инвентаря вернутся игроку.

## Настройки

Список модов, кнопка «Настройки», или `config/gearinventory-client.toml` и `serverconfig/gearinventory-server.toml` в мире.

## Защита вещей

Броню с вещами нельзя вложить в шалкер, бандл или другую броню, переплавить, слить с другой или сжечь на земле.
Сломалась: вещи выпадут рядом. Бездна и исчезновение предмета через 5 минут уничтожают её, как любой предмет.

## Сборка

`gradlew build`, тесты `gradlew runGameTestServer -PwithTacz -PwithSB` (нужны jar в `libs/`).
Звук сердцебиения и текстуры сделаны для этого мода.
