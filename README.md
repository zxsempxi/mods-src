# Create Spore Test: свои моды

NeoForge 21.1.262, Minecraft 1.21.1, Java 21.

- `gearinventory`: «Тактический инвентарь».
- `sbwtweaks`: Superb Warfare без транспорта, лут в сундуках всех модов.
- `armorrigs`: старый мод «Разгрузки», заменён на gearinventory.
- `modlist.txt`: моды сборки.
- `PLAN.md`: план мода инвентаря.

Чужие jar из `gearinventory/libs` в репозиторий не входят, их список в `gearinventory/build.gradle`.
